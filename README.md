# Project Foundry — Android downloads

Official signed Android ARM64 builds of Project Foundry. The game source remains private.

Open the Releases tab for available builds. If Releases is empty, no APK has been published yet.

Releases contain the APK and SHA256.txt. The latest.json update manifest is promoted only after original-signature, package, version and anonymous download checks. No signing keys, private source or build logs are published here.

Install updates over the existing copy to retain app data. Android asks you to approve installation. Install the first configured updater build manually once; later versions are checked at startup or under Settings → Game updates.
